# 基金估值速查

原生 macOS 应用，支持自选基金持仓盈亏计算、多数据源容灾、定时自动刷新。

## 功能
- 添加/删除/编辑自选基金（代码、成本价、份额）
- 实时估算净值及涨跌幅
- 场内 ETF 按腾讯行情 IOPV（基金份额参考净值）实时估值：成分股实时价 × 盘前申赎清单（PCF），行情系统每 15 秒更新；同步显示二级市场价格折溢价率，腾讯净值缺失时自动用新浪基金净值接口兜底
- 场外基金按季报前十大重仓股 × 实时涨跌估算盘中估值（东财 F10 持仓，本地缓存 24 小时；持仓滞后一个季度、覆盖率有限，仅供参考，仅供个人使用请勿对外发布）
- 持仓盈亏金额和收益率
- 多数据源自动容灾（天天基金 → 腾讯证券 → 新浪基金净值）
- 定时更新时段设置（默认交易时段 9:30-11:31, 13:00-15:01）
- 深色模式自适应

## 数据来源
- 天天基金（主）
- 腾讯证券（备用）
- 新浪基金（备用）

所有数据仅供参考，最终净值以基金公司公布为准。
